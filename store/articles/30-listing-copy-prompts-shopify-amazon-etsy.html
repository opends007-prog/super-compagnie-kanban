30 Listing-Copy Prompts: Titles, Bullets & Keyword Density for Shopify, Amazon, and Etsy Sellers

A copywriter who has written 2,000+ listings still stares at a blank doc when the next SKU lands. The prompts below are the ones I actually open. Each one is paired with the platform it fits best, the input it expects, and the failure mode it prevents. Use them as a starting point, not a script — the best listings come from a writer who knows when to break the formula.

Before you prompt: the three numbers that decide everything

Every prompt below assumes you've already done this homework. If you haven't, stop and fill these in first:

  1. Primary keyword — the exact phrase a buyer types. Pull it from Amazon search suggestions, Etsy search autocomplete, or Shopify's search analytics. Don't guess; type the root word into Amazon and steal the autocomplete phrases.
  2. Two secondary keywords — close variants or use-cases. "Stainless steel water bottle" might pair with "insulated" and "leak proof."
  3. The buyer objection — the one thing that makes them put the item back. Price? Sizing? Durability? Compatibility? If you can't name it, you don't know the buyer yet.

Without these three numbers, every prompt below will produce generic copy. With them, the same prompts produce listings that rank and convert.

Title prompts

1. The "[Primary keyword] + [objection-killer] + [use case]" formula Best for: Amazon, Etsy Input: primary keyword, the objection, the use case Example output: "Stainless Steel Water Bottle — Leak Proof Lid, Keeps Cold 24 hrs — for Hiking and Office" Prevents: titles that read like spec sheets instead of search queries.

2. The "long-tail mirror" prompt Best for: Etsy Input: paste 5 winning competitor titles into the prompt and ask the model to extract the shared noun phrases, then rebuild a title using the same phrases in a fresh order. Prevents: Etsy titles that bury the searchable phrase after a brand name.

3. The "character-budget" prompt Best for: Amazon (200 char limit), Etsy (140 char limit) Input: a draft title + the platform's character limit Ask: "Rewrite to fit in [N] characters without losing the primary keyword or the strongest benefit word." Prevents: titles that get truncated mid-benefit on mobile.

4. The "what would the buyer type at 11pm" prompt Best for: all three Input: the product Ask: "Write the title a tired parent would type into a search bar at 11pm when they need this product by morning." Prevents: titles written for the seller's ego instead of the buyer's panic.

5. The "feature-to-benefit swap" prompt Best for: Shopify, Amazon Input: a feature-heavy draft title Ask: "Replace each feature word with the benefit the buyer actually experiences." Example: "600D polyester" → "holds up to daily schoolyard abuse." Prevents: spec-dump titles that rank but don't click.

Bullet prompts

6. The "5-bullet skeleton" prompt Best for: Amazon Input: product, primary keyword, three features, the objection Ask: "Write 5 bullets. Bullet 1: who it's for and the main outcome. Bullets 2-4: features translated to benefits, each starting with a different word. Bullet 5: risk reversal (warranty, returns, guarantee)." Prevents: five bullets that all start with "Made of…" or "Features…"

7. The "objection as bullet" prompt Best for: Amazon, Shopify Input: the buyer objection Ask: "Write a bullet that names the objection in the first 6 words and resolves it in the rest." Example objection: "Will it fit my laptop?" → "Fits up to 16-inch laptops — internal dimensions 15.2 × 10.8 in." Prevents: bullets that skip the question the buyer is actually asking.

8. The "verb-first" prompt Best for: all three Input: a draft bullet Ask: "Rewrite starting with a verb the buyer will do, not a verb the product does." "Keeps drinks cold" → "Bring ice-cold water to the trailhead." Prevents: passive, product-centric bullets that read like a manual.

9. The "specificity ladder" prompt Best for: Amazon Input: a vague bullet Ask: "Add the next layer of specificity: exact measurement, exact material, exact time, or exact count." "Spacious interior" → "Holds a 15-inch laptop, two notebooks, and a charger — 12L capacity." Prevents: bullets that sound like every competitor's bullets.

10. The "no-adjective" prompt Best for: all three Input: a draft bullet list Ask: "Strip every adjective that isn't doing measurable work. Replace each with a number, a material, or a verb." Prevents: "premium," "high-quality," "stylish" filler that Amazon's style guide actually warns against [1].

Description prompts

11. The "first sentence is the answer" prompt Best for: Shopify, Etsy Input: the product Ask: "Write the first sentence so a buyer who reads nothing else knows what the product is, who it's for, and the single best reason to buy." Prevents: descriptions that open with brand story instead of buyer value.

12. The "objection paragraph" prompt Best for: Shopify Input: top 3 buyer objections Ask: "Write one short paragraph per objection, each opening with the objection phrased as the buyer would phrase it." Prevents: a description that ignores the three reasons people don't buy.

13. The "sensory paragraph" prompt Best for: Etsy (where buyers shop emotionally) Input: the product Ask: "Write one paragraph using texture, weight, sound, or scent — whichever applies. No benefit claims, just the physical experience." Prevents: Etsy descriptions that read like Amazon bullets.

14. The "specs as a table" prompt Best for: Amazon, Shopify Input: dimensions, materials, compatibility, care instructions Ask: "Format as a two-column table. Left column: spec name. Right column: value. No marketing language in the table." Prevents: specs buried in paragraphs where scanners miss them.

15. The "FAQ block" prompt Best for: Amazon (if A+ Content is available), Shopify Input: 5 questions pulled from real customer messages or Reddit threads Ask: "Answer each in 1-2 sentences. Lead with the answer, not the question restated." Prevents: FAQ blocks that waste the buyer's time.

Keyword density prompts

16. The "density audit" prompt Best for: Amazon, Etsy Input: the full listing (title + bullets + description) Ask: "Count occurrences of the primary keyword and each secondary keyword. Report density as a percentage of total words. Flag any keyword used 0 times or more than 3 times per 100 words." Prevents: keyword stuffing (which hurts Etsy SEO [2]) and accidental omission (which hurts Amazon indexing).

17. The "natural insertion" prompt Best for: all three Input: a paragraph missing the primary keyword Ask: "Insert the primary keyword in the most natural spot. If no natural spot exists, rewrite the sentence so one exists. Do not add the keyword if it requires awkward phrasing." Prevents: forced keyword placement that reads like spam.

18. The "competitor gap" prompt Best for: Amazon Input: top 3 ranking competitor listings + your draft Ask: "List every bigram (two-word phrase) the competitors use that your draft doesn't. Suggest where each could fit without padding." Prevents: missing the secondary phrases the algorithm associates with the primary keyword.

19. The "backend keyword" prompt (Amazon-specific) Best for: Amazon Input: the product, primary keyword, two secondary keywords Ask: "Generate backend search terms: no commas, no repeats of words already in the title, no competitor brand names, all lowercase, under 250 bytes total." Prevents: wasted backend keyword bytes on words Amazon already indexes from the title [3].

20. The "Etsy tag" prompt (Etsy-specific) Best for: Etsy Input: the product Ask: "Suggest 13 tags. Each must be a multi-word phrase a buyer would search, not a single adjective. No repeats of words already in the title (Etsy de-duplicates across title and tags)." Prevents: single-word tags like "blue" or "gift" that every competitor also uses [4].

Platform-specific edge cases

21. The "Amazon character-counter" prompt Input: a draft title Ask: "Count characters including spaces. If over 200, cut the least important phrase first. Never cut the primary keyword."

22. The "Etsy all-13-tags" prompt Input: the product, the title Ask: "Confirm exactly 13 tags, each under 20 characters, no word repeated from the title."

23. The "Shopify SEO meta" prompt Input: the product, primary keyword Ask: "Write a meta title under 60 characters and a meta description under 160 characters. Both must include the primary keyword once, naturally."

24. The "mobile truncation" prompt Input: the title Ask: "Show how the title will appear on a 6.1-inch mobile screen after Amazon/Etsy truncation. Flag the cut-off point."

25. The "A/B variant" prompt Input: a finished listing Ask: "Write one alternate title and one alternate bullet 1 that test a different primary benefit. Keep the primary keyword in both."

Workflow prompts

26. The "competitor teardown" prompt Input: 3 top-ranking competitor URLs Ask: "Extract their title formula, bullet structure, and the benefit words they repeat. Identify the gap my listing can fill."

27. The "review-mining" prompt Input: 20 customer reviews (yours or a competitor's, if publicly available) Ask: "List the exact phrases buyers use to describe what they love and what they hate. Use the love phrases in bullets; address the hate phrases in the description."

28. The "voice consistency" prompt Input: 3 past listings you've written Ask: "Extract the voice rules: sentence length, punctuation habits, banned words. Apply them to this new draft."

29. The "compliance check" prompt (Amazon-specific) Input: the full listing Ask: "Flag any claims that violate Amazon style: subjective superlatives ('best', '#1'), promotional phrases ('sale', 'free shipping'), unverifiable claims ('guaranteed to')." Amazon's style guide bans these [1].

30. The "ship-it checklist" prompt Input: the finished listing Ask: "Confirm: primary keyword in title, primary keyword in first bullet, primary keyword in first 100 words of description, all 13 Etsy tags filled, all Amazon backend bytes used, no banned phrases, character counts within limits. Output pass/fail per item."

How to use this list

Pick three prompts per listing: one title, one bullet, one keyword audit. Run them in that order. The title prompt forces you to commit to a primary keyword; the bullet prompt forces you to translate features into buyer outcomes; the audit prompt catches the gaps before you publish. The other 27 prompts are there when a specific problem shows up — don't run all 30 on every SKU or you'll spend more time prompting than selling.

The prompts are scaffolding, not scripture. The best listings I've written started with a prompt and ended with me ignoring half of what came back. Use the prompt to break the blank page, then rewrite in your own voice.
